`TICKET-0053` updates the MNIST readiness report to cover the phase-17 cached
dataset work.

`mnist-dataset-metrics`, so it reads the metrics artifact generated by the same
e2e run. It marks derived-mask command wiring, cached dataset training sweep
coverage, structured dataset metrics, and `full_dataset_training` true.

is still generated StableHLO-shaped artifacts plus host-side cached IDX
training and metrics, not a full classifier run through IREE, StableHLO runtime
tooling, or expanded LLVM lowering.
