# MNIST Forward

`TICKET-0028` is complete.

LeanAX now lowers an MNIST-shaped forward module. The new `mnist-forward` case
takes flattened fixture images shaped `2x784`, a first dense layer
`784x8 + 8`, ReLU, and a final dense layer `8x10 + 10`, returning logits shaped
`2x10`.

The hidden width is deliberately small so the golden stays readable while the
public input and output shapes match the classifier target. The e2e manifest
checks the artifact with golden text, MLIR generic parsing, lowering manifest
validation, and deterministic Python numeric values. It also adds
`bad-mnist-forward-shape` for the expected dot-product inner-dimension failure.
