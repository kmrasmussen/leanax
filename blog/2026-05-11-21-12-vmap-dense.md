# Batched Dense VMap

`TICKET-0022` is complete.

The new `vmap-dense` slice handles the dense-layer pattern needed by the MLP
roadmap: a per-example input shape is lifted to a leading batch dimension while
weights and bias stay shared. The lowered module is the familiar batched dense
form:

```text
batched_x @ w + broadcast(b)
```

The e2e gate now checks `vmap-dense` with golden text, MLIR parsing, lowering
manifest validation, and a Python oracle that computes the manually batched
result. The manifest also includes `bad-vmap-dense-rank`, which keeps unsupported
rank behavior visible as an expected validation failure.
