# TICKET-0038: MNIST Train Command Wrapper

## Problem

The ten-class classifier smoke exists as an e2e Python script, but there is no
stable user-facing command that communicates how to run the current classifier
path.

## Goal

Add a command wrapper for fixture-mode MNIST classifier training, using the
checked artifacts already generated by LeanAX.

## In Scope

- A command shape such as `leanax train mnist-mlp --mode fixture`, or the
  closest existing CLI-compatible wrapper.
- Stable metrics: mode, epochs, samples, batches, first/final loss,
  first/final accuracy, and artifact paths.
- Clear failure messages when required generated artifacts are missing.
- Documentation in the README and roadmap.

## E2E Focus

Add a manifest-covered command smoke that runs fixture mode and checks stable
metric fields.

## Acceptance Criteria

1. One documented command runs fixture-mode ten-class classifier training.
2. The command uses checked LeanAX artifacts instead of silently falling back to
   unverified host math.
3. Metrics print with stable names suitable for future parsing.
4. Missing artifact errors tell the operator which generation step is needed.
5. The full Nix e2e gate passes.

## First Slice

Wrap the existing `mnist-classifier-smoke` behavior without changing model
math.
